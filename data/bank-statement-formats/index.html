Bank statement formats

Bank-by-bank PDF statement layouts (Chase, Bank of America, Wells Fargo, Capital One, RBC, TD) and sample download files. QFX and OFX are tagged text files that banks and card issuers offer as transaction downloads. OFX (Open Financial Exchange) is the open standard, and QFX is OFX with Intuit's INTU.BID tag added so Quicken accepts it. Neither carries an opening balance, so a download alone can't prove a month is complete.

Every bank name, account number, payee and amount in these files is made up.

How to use these files

  • Open a .qfx or .ofx file in any text editor. The comments explain each block.
  • Strip the comments before testing an import, because some readers reject them.
  • To read either format in code, the open-source Python library ofxtools handles OFX 1.x, OFX 2.x and QFX.
