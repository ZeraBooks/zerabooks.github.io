README

Bookkeeping automation task map

A bookkeeper takes on more clients without hiring by automating the work every client repeats each month: getting statements in, categorizing, matching, reconciling and the month-end report. Judgment, client questions and sign-off stay with the bookkeeper. This repo maps each recurring task to the part software can do and the review step that stays with you.

Files

File What it is
task-map.csv 15 recurring bookkeeping tasks: how often, how it is done by hand, what software can do, what stays with the bookkeeper and the check that proves it was done right.
time-log.csv A one-client, one-month time log with a fictional sample month already filled in. Replace it with your own.
time_log_summary.py Totals the log by task and splits the minutes into work software can take, work it can take part of, and work that stays with you. Python 3, standard library only.
move-a-client-checklist.md The steps to move one client into new software from a trial balance and the open invoice and bill reports.

How to use it

  1. Pick one ordinary client and log every minute you spend on their books for one month in time-log.csv, one row per sitting. Use the task names from task-map.csv so the totals group cleanly.

  2. Mark each row Yes, Partly or No in the last column, using the "What software can do" column of the task map as a guide.

  3. Run the summary:

    python3 time_log_summary.py time-log.csv

  4. Look at the Yes and Partly lines. Those are the hours that repeat for every client, and the ones to automate first. The No lines are the work clients actually pay you for.

  5. Move your slowest client with move-a-client-checklist.md and time the next month against the last one.

The sample month

The fictional client in time-log.csv took 425 minutes (7.1 hours) in October 2026. Of that, 190 minutes were tasks software can take, 180 were tasks it can take part of, and 55 stayed with the bookkeeper: client questions, reviewing the reports and closing the month. Categorizing alone was 95 minutes, the largest single task. All figures are fictional.

What a review check is for

Every row in the task map ends with a check. Automation is only safe when the result can be proven: a reconciled account equals its printed closing balance, imported lines equal the lines on the statement, and open receivables agree with the aging report. If you can't state the check, keep the task manual.

FAQ

Will automation replace bookkeepers?

It replaces the typing, not the bookkeeper. Categorizing, matching and reconciling are being automated. Judgment, client conversations and sign-off are not, and bookkeepers who automate the first part take on more clients with the time.

How much time does automation save per client?

It depends on the client, so time it. Log one month before and one month after on the same client and compare the totals from the script.

Which client should I move first?

The one whose month takes longest. Statement-heavy clients with many accounts and cards show the biggest change.
